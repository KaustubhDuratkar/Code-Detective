# CodeDetective — Project Statement

## 1. Problem Statement

Learning Java programming is not limited to writing correct programs; students must also be able to identify, understand, and fix errors in existing code. Beginners often struggle with debugging because error messages, incorrect logic, exceptions, and programming concepts can be difficult to interpret without sufficient practical experience.

Traditional programming exercises mainly focus on writing programs from scratch and provide limited opportunities for students to practice debugging in an engaging way.

**CodeDetective** aims to solve this problem by providing an interactive command-line environment where users investigate broken Java programs, analyze evidence, identify programming bugs, and understand the appropriate solution. The project transforms debugging practice into a detective-style learning experience.

---

## 2. Scope of the Project

The scope of CodeDetective includes the development of a Java-based command-line debugging and learning system.

The system covers:

* Investigation of predefined Java debugging cases.
* Identification of compilation, runtime, logical, and conceptual errors.
* Presentation of broken Java code and error evidence.
* Validation of the user's bug diagnosis.
* Explanation of the identified problem and its correct repair.
* Difficulty-based debugging challenges.
* XP and level progression.
* Detective ranks and achievement tracking.
* Hint functionality.
* Random case selection.
* Daily debugging challenges.
* Case history and progress tracking.
* Local file-based storage of user progress.
* Input validation and exception handling.

The current project focuses on a local command-line environment and does not require an internet connection, external database, or graphical user interface.

Future versions may extend the project with a graphical interface, database connectivity, online leaderboards, automatic code execution, and AI-assisted debugging.

---

## 3. Target Users

### Primary Users

**Java Programming Students**

Students who are learning Java and want to improve their ability to identify and understand programming errors.

### Secondary Users

**Beginner Programmers**

Users who have basic Java knowledge and want additional practice with debugging and problem-solving.

**Programming Instructors**

Teachers or instructors can use the debugging cases as supplementary exercises for programming practice.

**Academic Project Evaluators**

The system demonstrates practical application of Java programming and Object-Oriented Programming concepts in an interactive project.

---

## 4. High-Level Features

### 4.1 Interactive Debugging Cases

Users can investigate multiple Java programming cases containing:

* Case story
* Broken source code
* Evidence or error message
* Difficulty level
* Bug category
* Correct repair

### 4.2 Bug Diagnosis

Users can enter their own explanation of the suspected bug. The system analyzes the response using predefined keywords and determines whether the diagnosis is correct.

### 4.3 Hint System

Users can request hints when they are unable to identify a bug. Using a hint consumes XP, encouraging users to solve cases independently.

### 4.4 XP and Level System

Successfully solving cases awards experience points. The accumulated XP determines the user's level and detective rank.

### 4.5 Detective Ranks

The system provides progressive ranks such as:

* Rookie Detective
* Junior Debugger
* Code Sleuth
* Bug Hunter
* Senior Detective
* Code Master

### 4.6 Achievement System

The system tracks user achievements based on debugging performance and milestones.

Examples include:

* First Blood
* Bug Hunter
* Master Detective
* Three Case Streak
* No Hints Needed

### 4.7 Random Case Challenge

The system can randomly select an unsolved debugging case, providing a different challenge during each investigation session.

### 4.8 Daily Challenge

A date-based challenge provides the user with a designated debugging case for the day.

### 4.9 Case History

Users can view their completed cases and overall investigation progress.

### 4.10 Persistent Progress

The system stores important detective information such as XP, solved cases, hints, streaks, and attempts in a local file so that progress can be continued later.

---

## 5. Expected Outcome

The expected outcome of CodeDetective is an interactive and beginner-friendly Java debugging system that encourages students to practice identifying programming errors while developing their analytical and problem-solving skills.

The project also demonstrates the practical application of Java Object-Oriented Programming, exception handling, collections, file handling, and modular software design in a single educational application.
